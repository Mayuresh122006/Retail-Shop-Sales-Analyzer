RETAIL SHOP SALES & CUSTOMER BUYING PATTERN ANALYZER

The project uses sample sales records dated up to September 2026 only.
Charts use different styles:
- Pie chart: category-wise sales share
- Horizontal bar chart: product buying pattern
- Line graph: monthly sales trend

Install:
pip install pandas numpy matplotlib

Run:
python main.py

Open this folder in VS Code and run the program from the terminal.
Sales entered through Add New Sale are saved in sales_data.csv.
